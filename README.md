# Enterprise IAM Risk Analytics Workflow

## Project Overview
Built an end-to-end IAM risk analytics workflow using Alteryx to analyze user behavior, classify security risks, integrate role mapping, and generate audit-ready reporting outputs.

## Tools Used
- Alteryx
- Power BI
- Excel
- SQL Concepts

## Features
- Data Cleansing
- ETL Workflow Automation
- Risk Scoring
- User Activity Classification
- IAM Role Mapping
- Risk Categorization
- Summarization & Reporting

## Workflow Architecture

User Activity Data
↓
Data Cleansing
↓
SecurityFlag Logic
↓
ActivityLevel Classification
↓
RiskScore Calculation
↓
RiskCategory Classification
↓
Role Mapping Join
↓
Summarize & Export

## Business Value
This project demonstrates enterprise-style IAM analytics workflows used for:
- Risk monitoring
- Access governance
- Audit reporting
- User behavior analysis
- Compliance analytics
